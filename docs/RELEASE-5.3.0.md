# Patriots PC 5.3.0 — Português (Brasil)

Brazilian Portuguese is now the third bundled official language, alongside English and Turkish.

- **299 launcher texts and 1,862 active game/runtime texts** supplied by **[(Sanju Vinho e Fumaça)](https://steamcommunity.com/id/SanjiVinsmokeBRASIL/)**. The submitted translations and credit are retained.
- Select **Português (Brasil)** in the launcher. It changes the launcher immediately and the game on its next launch, including loading text, runtime prompts and room/status strings.
- Keyboard/gamepad prompts still follow the current device and bindings. Discord presence continues to use real room/game telemetry.
- Added the missing Portuguese accent glyphs to two locale-specific HUD bitmap fonts. Existing glyph pixels, shared assets and other languages are retained.
- The remaining 74 catalogue records are legacy N-Gage service metadata and protected technical references. They retain their English fallback; they are not missing game dialogues.
- Contributor credit is visible in **LANGUAGES / IDIOMAS** and included in both JSON files.

## Downloads

- **Full package:** extract the complete folder and open `Metal Gear Solid Mobile.exe`.
- **Update ZIP:** close the game and launcher, then extract over the existing game folder. It adds the Portuguese tables/fonts/catalogues and updates the launcher/runtime without shipping personal settings or saves.

All three languages share the same save files. Keep a backup when replacing an existing installation. Distribution files contain no personal saves.

Android uses a separate **android-v1.1.0** release, the same Portuguese translation and its existing verified APK update channel. PC ZIP files are ignored by the Android updater.

Checks include catalogue/token validation, all fourteen compiled Portuguese DAT tables, font round trips/pixel preservation, actual Portuguese launcher renders, native keyboard/Xbox/PlayStation/rebinding tests and a Windows game boot into the opening 3D scene. These checks do not constitute a complete playthrough.
